# Re(Visiting) Time Series Foundation Models in Finance (Rahimikia, Ni, Wang) - arXiv:2511.18578 [library id: doi:10.2139/ssrn.5770562, merged with arXiv:2511.18578]

Read: full text via arXiv HTML fetched through WebFetch (summariser-extracted; numbers below should be spot-checked against the PDF before they enter a paper). Accessed 2026-10-01.

**Problem.** Do off-the-shelf / fine-tuned / finance-pretrained TSFMs forecast daily stock excess returns better than standard ML baselines?
**Method.** Chronos (8M-710M) and TimesFM (8M-500M) evaluated in three regimes: zero-shot public weights, fine-tuning, and pre-training from scratch on finance data (US, then global 94 countries + 153 JKP factors). Benchmarks: OLS/Lasso/Ridge/ENet/PCR, XGBoost/CatBoost/LightGBM, small NNs.
**Data.** Daily excess returns 1990-2023; ~18.1M US obs, ~10,000 securities; expanding window, OOS 2001-2023, 23 yearly refits; windows 5/21/252/512 days; returns winsorised to [-1,1], missing imputed with country-day medians; stocks <$5 and bottom 5% cap dropped.
**Results.** Zero-shot Chronos-large (512d): R2_OOS -1.37%, ann. return 20.17%; TimesFM-500M: R2_OOS -2.80%, ann. return -1.47%. CatBoost benchmark: R2_OOS -0.10%, dir. acc ~51%, Sharpe 6.79 (long-short decile, gross of costs as far as extractable). Fine-tuning gives limited gains. Pre-training from scratch on US returns: Chronos-small R2_OOS -0.59%, ann. 36.84%, Sharpe 5.42; global data + JKP factors: Chronos-small dir. acc 51.74% vs CatBoost 51.16%.
**Stated limitations.** Daily frequency; univariate; possible look-ahead in public TSFM pretraining; results hinge on Chronos/TimesFM; window-length sensitivity.
**Critique.** (i) Even the best finance-native TSFM only matches a CatBoost baseline; the claim "TSFMs can outperform" rests on ~0.5pp directional accuracy. (ii) Sharpe ratios of 5-7 for long-short deciles signal a gross, cost-free, microcap-tilted evaluation: do not use as headline. (iii) The useful finding for us is negative-then-conditional: generic pretraining does not transfer to returns; finance-specific pretraining helps, which is the regime a finance JEPA would live in. (iv) Pre-training corpus contamination for public TSFMs is acknowledged but not quantified.
**Relevance.** Baseline protocol for any return-forecasting probe of a finance JEPA (expanding window, JKP factors, CatBoost as the bar).
