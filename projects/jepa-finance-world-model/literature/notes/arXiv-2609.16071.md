# arXiv:2609.16071 World Models for Cross-Machine CNC Transfer under Partial Sensor Overlap
Read: HTML full text via WebFetch extraction (2026-10-01). Industrial time-series (not finance) but the cleanest "matched from-scratch" test of latent-predictive pretraining under *partial observability across domains* (17 source sensors vs 10 shared target sensors).
- **Findings:** (1) latent-predictive pretraining brings **no in-domain forecasting gain** over matched training from scratch: 0.811+-0.022 vs 0.813+-0.022 RMSE, p=0.76; locked model 0.822+-0.009 is worse than an RSSM baseline 0.759 and an MLP 0.771 on source validation. (2) zero-shot on the unseen machine the transferred model (0.546 RMSE) beats persistence (0.654) but trails PatchTST (0.503) and iTransformer (0.498) that use input normalisation; RevIN alone closes the gap (0.495+-0.004) at a cost in calibration.
- **Data:** source 29,785 rows at 1 Hz over 62 sessions; target 1,503,915 controller-cycle records over 7 runs; windows 18,267/3,423/5,189 (train/val/test).
- **Limitations (authors):** single machine pair; 7 target runs; target read once, RevIN ablation is a second read; command sensitivity not verified (shuffled commands change RMSE by <0.005); every arm used the latent objective, so no target-only arm without it.
- **Relevance:** third independent negative/neutral result for latent-predictive pretraining on tabular/time-series (with arXiv:2609.31680 and arXiv:2609.25541), and a warning that a command/action-conditioned latent can be insensitive to its conditioning input. Model-selection discipline (select on source only, lock, read target once) is worth copying for pre-registration.
