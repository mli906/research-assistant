**These two items correct the early-scan statement that no finance JEPA exists.**

**Fin-JEPA (SSRN 6855118; code https://github.com/cedricwyh/fin-jepa, MIT).** Per README/web search snippet: PriceEncoder MLP (GELU, LayerNorm) + 4-layer causal Transformer predictor, SIGReg regulariser against collapse, 64-d latent of daily equity features, 367K params, 6,230 US equities 2010-2026 (2.07M training samples); loss 1.369 -> 0.706 in 50 epochs, no collapse; latent prediction beats an identity baseline by 10.1%; prediction error as trading signal over 300 stocks: "weak-to-negligible". README gives no splits or numeric tables. Single-author, no peer review known. Treat as a proof of concept; confidence low.
**FinJEPA on Hugging Face (ashesh8500/finjepa).** Action-conditioned JEPA "for portfolio optimization" (actions = portfolio weights, long/short/flat, hedge flags). Model card says it was generated by an automated research agent and reports no evaluation. Not evidence.
**ICML 2026 poster (Mahns, Balestriero, Assran; per abstract only).** Permutation-invariant tokenizer maps each day's unordered per-asset features to learned factor tokens; temporal JEPA with masked prediction yields a daily market-state embedding. Embeddings strongly associated with second-moment structure (realised vol, correlation concentration, effective factor dimension), weakly with direction; help predict gradual recovery but not sudden stress onsets; latent regimes align with news-topic shifts without text supervision. Authors include the JEPA originators' circle (Assran, Balestriero), so this is the credible reference point.
**Implication.** Novelty of "JEPA for finance" per se is gone; open space is (a) firm-level / panel / nowcasting / action-conditioning, (b) honest evaluation against TSFMs, tabular FMs and econometric baselines, (c) counterfactual validity. Verify the ICML paper's full text before any novelty claim.
