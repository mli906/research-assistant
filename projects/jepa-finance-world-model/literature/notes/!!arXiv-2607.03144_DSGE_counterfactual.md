# arXiv:2607.03144 DSGE-Gym / "DSGE as a Structured World Model: Benchmarking Counterfactual Generalization in Economic Worlds"
Read: HTML full text via WebFetch extraction (2026-10-01). Highest-relevance finance-specific item in the methods facet (not JEPA, but a world-model-for-economics test bed).
- **Benchmark:** 8 DSGE environments (RBC 11 vars, NK 15, TANK 22, TCM 45, NAWM 230, plus DMP, E-NK, Firm), unified world-model interface with off-path counterfactual test sets; task T1 = one-step prediction given state + next-period shock/action. Multi-step (T2) and planning regret (T3) released but not analysed.
- **Models:** ridge, MLP, LSTM, Transformer, NextLat (next-latent self-prediction), vs first-order and third-order DSGE oracles. No JEPA/Dreamer/TD-MPC2 in the extraction.
- **Results:** on-path normalised RMSE ~0.004-0.08; under 5-sigma tail shocks sequence/attention models reach RMSE 3.3-3.8 (about two orders of magnitude worse): "flexibility correlates with off-path fragility". Training on DSGE-synthesised wide-coverage data cuts policy-regime errors 10-280x where the counterfactual shifts the ergodic support (RBC, DMP, E-NK, Firm), ~3-8x elsewhere, tail errors 2.5-3x; NAWM (230 vars) tail error cut only ~40% (3.4->2.1, 3.5->1.9). Negative: first-order DSGE oracle is worse than the black-box MLP off-path (tail RMSE 0.80 vs 0.37).
- **Authors' limitations:** structure vs coverage not disentangled (no regime-dummy-VAR or perturbation-augmentation control); structure imposed not learned; misspecification risk ("synthetic off-path data can be confidently wrong"); baselines modestly tuned; one-step only.
- **Relevance:** direct evidence that learned world models fail off the data support, which is exactly the counterfactual use. Gives a ready test bed (synthetic, known mechanism) for an action-conditioned JEPA vs sequence baselines. Confidence that results generalise to real economies: low.
