# arXiv:2607.27017 What Can Latent World Models Know? Physical-parameter identifiability
Read: HTML full text via WebFetch extraction (2026-10-01).
- **Setting:** which hidden physical parameters (stiffness, mass, drag) become linearly decodable from latent states of learned world models; PokeWorld 2D simulation + real-robot RH20T force.
- **Findings:** prediction *targets* shape what is recoverable: stiffness readable only if touch is a prediction target (R^2 0.50 with targets vs -0.03 without; input-only does not help); mass weak (0.13-0.29); drag weak (0.07-0.14). Multi-horizon targets raise velocity readout 0.11 -> 0.35. **Readability != usage:** drag weakly readable (R^2 about 0.06) yet forecasts depend on it (slope ratio 1.04); coordinate-target training made drag readable (0.41) but forecasts ignore it (0.12). Real robot: force R^2 0.88 only when force is both input and target.
- **Limitations:** 2D sim, three parameters; ground-truth object state in intervention experiments; no formal identifiability theory (cites concurrent theory).
- **Relevance:** warns that linear probes of a financial latent (e.g. "does it encode credit risk?") can mislead in both directions, and that predicting a variable as a target (not merely feeding it as input) determines whether the latent encodes it. Design implication: put the variables you want to reason about (revenue, headcount, cash flow) in the *target* views (inference from the evidence, M).
