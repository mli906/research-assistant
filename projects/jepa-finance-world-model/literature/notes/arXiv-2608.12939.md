# Diagnosing JEPA world models with Action-Conditioned Predictive Consistency, ACPC (arXiv:2608.12939)
An, Wu, Dong et al., Aug 2026. Read: arXiv HTML via summarising fetch tool (2026-10-01). (An earlier PDF fetch returned a different, partly wrong description; only the HTML extraction, which quotes equations, is used here.)

- **Problem:** JEPA latent rollouts can be corrupted by visual perturbations; "two observations are the same state only if their action-conditioned consequences agree" (bisimulation view).
- **Method:** ACPC = divergence between rollouts of clean vs perturbed observations under identical action sequences. Two screens: Invariance Radius (IR, a q-quantile of normalised clean-vs-perturbed rollout sensitivity over anchors) and Separation Rate (SR, fraction of different-state pairs whose distance exceeds IR plus a margin). Proposition 1: ACPC bounds the change in multi-step prediction error; Proposition 2 bounds planning-cost change.
- **Eval:** LeWM (primary) and PLDM on TwoRoom, PushT, Reacher, OGBench-Cube. Using ACPC as a training regulariser: 55.9+-4.7% reduction in error drift vs base; 15.2+-2.0% lower cross-task test MAE. IR-SR screen thresholds (0.3, 0.95): balanced accuracy 0.900. Under blur/resize: sign agreement in 22/24 comparisons, Spearman 0.835.
- **Limitations (authors):** needs an unaugmented reference checkpoint; only Gaussian-noise, one blur and one resize severity; IR threshold at edge of tested range.
- **Use for us:** a template for "does the latent state carry decision-relevant information, or just appearance". Finance analogue: perturb a nuisance (e.g. reporting-lag, restatement noise, vendor field renaming) and check the rollout under the same macro path is invariant while truly different states stay separated. Note it tests robustness to observation noise, not causal validity of actions. Confidence: medium.
