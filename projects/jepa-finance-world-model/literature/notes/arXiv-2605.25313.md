# arXiv:2605.25313 UWM-JEPA: Predictive World Models That Imagine in Belief Space
Read: HTML full text via WebFetch extraction (2026-10-01).
- **Idea:** latent state is a density matrix rho (d_total=16; extraction states 8 for system, 2 for environment) on a bipartite system-environment space; predictor is unitary conjugation U^k rho U^-k so rollout cannot silently dissipate represented uncertainty. EMA target encoder, stop-gradient, loss after partial trace.
- **Findings:** teacher-forced JEPA makes actions inert (||H1||/||H0|| about 0.03); counterfactual targets restore action sensitivity (1.00 +- 0.15). Hidden-velocity CartPole-style task: UWM-JEPA-CF 0.770 +- 0.011 accuracy vs LSTM-JEPA-CF 0.530 (majority class). Frozen-probe R^2 0.901 vs 0.894 (Welch p=0.70): the difference is in the predictor, not the encoder. Blind rollouts: advantage at k<=5, both poor beyond k=10.
- **Limitations (authors):** action binding needs simulator-state access during training (so no passive-video use); only oscillator/CartPole settings; no HMM or real data.
- **Critique/relevance:** very small-scale, synthetic, quantum-flavoured state; evidence is that belief-carrying predictors help for hidden-state tasks. The "teacher forcing makes actions inert" result is a generic warning for any action-conditioned JEPA trained on observational data where the next state is already informative. High relevance to pillar 3, low maturity.
