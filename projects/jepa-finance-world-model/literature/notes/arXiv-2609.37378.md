# arXiv:2609.37378 Do-JEPA: From Masking to Intervention in Latent World Models
Read: HTML full text via WebFetch extraction (2026-10-01).
- **Idea:** from one saved simulator state run action a and a reference action a0; train to predict the latent *difference* dz = z^a - z^a0 with effect, support (where the action enters), propagation (edge), invariance and context losses.
- **Results:** synthetic SCM: support accuracy 99.95%; edge AUROC 0.975 with propagation loss vs 0.624 without; LeWM Push-T: latent effect RMSE -28.4% vs information-matched control, physical effect error -13.5%; CausalWorld: responsive effect error about -20% under physics shifts, latent context shift -66%; cost 51-53% higher factual prediction error when training from scratch. Baselines: observational JEPA, augmentation control, C-JEPA-style masking, effect-loss-only.
- **Hard requirement (authors):** exact simulator state savepoints, two rollouts per pair, known intervention and reference action, object-aligned slots. "Real trials share neither noise nor exact state, so differences ... are noisy and may be biased."
- **Relevance:** states precisely why observational JEPAs cannot separate "what an action caused from what merely co-occurred with it", and shows the fix needs paired counterfactual rollouts. In finance, the only place those exist is a simulator (DSGE-Gym arXiv:2607.03144, agent-based or calibrated models). That points to a design: train action-effect heads on synthetic paired rollouts, validate against real event studies (design suggestion, speculation).
