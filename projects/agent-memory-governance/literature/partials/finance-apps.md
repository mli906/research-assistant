## 6. Gaps (my observations; confidence in brackets)

1. **No disclosure of agent-memory governance by any bank** (high). Retention talk is about vendor ZDR/no-training. Scoping, retention and erasure of the *bank's own* agent memory per client are undocumented publicly.
2. **Industry and regulated-domain papers often avoid persistent memory on purpose** (Ryt stateless; DPM statelessness; SR-Fraud stateless decision with gated offline updates) (med-high). Research advisory agents assume rich personal memory (FinPerMA, Mem0/MemOS). *Nobody quantifies the utility cost of the "stateless" compliance choice against governed memory.* This is a clean empirical question.
3. **SAR/AML memory is a governance blind spot** (med). Co-Investigator reuses prior SARs as memory without access-control, retention or cross-subject-leakage analysis.
4. **Finance benchmarks measure recall and utility, not governance** (high). FinPerMA, Conv-FinRe and the wealth-mgmt benchmark have no cross-client leakage, erasure, consent or information-barrier tests. CRMArena-Pro tests confidentiality only as refusal to a direct request.
5. **Suitability as a memory-correctness criterion** (med). Staleness after life events (FinPerMA Post-Shock gap +5 pp) plus the Sell-Me-This-Stock evaluation blindness suggest a metric: "suitability-consistent recall under profile updates". I did not find one that persists across sessions.
6. **Retention conflict** (med): healthcare and privacy norms push "delete after use" while finance recordkeeping mandates retention. The design question of *which* memory artifacts count as books-and-records is unaddressed in the agent literature I found. Coordinate with the regulation scout.
7. **Information barriers / ethical walls for agent memory**: legal tech (Harvey+Intapp) is ahead of finance in shipping enforcement. I found no finance paper on MNPI walls in agent memory (med; arXiv's boolean search was weak on "information barrier", and one query was rate-limited).
