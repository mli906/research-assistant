## Scoop check — no hard scoop

Nothing published in the window covers the project's target combination (**governed promotion of per-client procedural memory into shared skills, with leakage bounds + erasure, evaluated against finance obligations**). The finance × skill × governance-eval intersection stayed empty across all 15 queries. The components kept moving, so watch:

- **SAGE** (arXiv:2609.36043) — a statistical acceptance gate for self-evolving agents; shows the naive "keep any edit that raises the aggregate" rule admits *permanent regressions*. Overlaps the promotion-gate / statistical-admission angle (alongside SR-Fraud arXiv:2609.27287, GRASP, FRAMES). General-domain, no privacy/finance. **Watch as a baseline for the promotion-gate contribution.**
- **Reliable Memory from Unstable Growth** (arXiv:2610.18427) — values playbook lessons by their *measured causal effect* via randomized experiments; same procedure can write a playbook that helps or falls **69.6 pts below no-playbook**. This is the "evaluate a skill's worth by RCT" method the project needs for a promotion-regression metric. **Closest methodological precedent; watch.**
- **MemJoin** (arXiv:2610.24359) — benchmarks *latent cross-session privacy*: the full history entails a sensitive relation though no single memory does. Direct precedent for the project's **composition-leakage** gap (INDEX new-gap #1). **Watch for the leakage-measurement contribution.**
- **MemForm** (arXiv:2610.14431) — memory-*formation* poisoning benchmark across 5 interfaces (Content, Evidence, Scope, Selection, Path). Integrity-eval precedent for the write/promote path.

## New since last scout (signal only)

**Procedural / skill eval benchmarks (new):**
- **PraxisMemBench** (arXiv:2610.20022) — first to benchmark the *interaction* of personal × procedural memory; procedures are user-conditioned (personal context decides which apply and when they change). Closest new benchmark to the project's procedural-memory-eval question.
- **EngramBench** (arXiv:2609.39284) — capability-grounded skill-evolution benchmark that structurally separates genuine abstraction from *rote solution leakage* (contamination). Directly attacks eval pitfall 5 (contamination).
- **RSE-Bench** (arXiv:2610.19910) — first benchmark for skill self-evolution under *ordinary non-adversarial noise* (perturbed instructions/evidence); robustness of distillation, not just clean success.
- **DSV-Mem** (arXiv:2610.08102) — multimodal memory in *professional workflows* with frequent revisions and *authority updates* — a non-finance analogue of the freshness/authority problem.

**Eval findings beyond success rate (new):**
- **More Memory, Worse Agents** (arXiv:2610.27406) — retaining *abstractions* (rules/skills) vs raw traces lets errors propagate through retrieval+reuse; "anti-persistence." Cautionary, pairs with 2610.18427.
- **Persistent Memory in Multi-Agent Inference** (arXiv:2610.07782) — controlled study: the persistent tier *does not buy accuracy* at n=100/arm and adds cost; decomposition helps, memory doesn't. A cost-vs-benefit cautionary result.
- **Lost in Implicit Routing** (arXiv:2610.18522) — skill-routing collapse at scale: with 1,000 irrelevant skills, loaded-skill recall 73.6% → 27.4%, zero-load rate 9.3% → 51.6%. Retrieval/reuse is a first-class failure mode as libraries grow.
- **Self-Evolving Agents Can Repair but Struggle to Generalize** (arXiv:2610.22984) — failure-only cold-start evolution; repair ≠ generalization.
- **Are Self-Evolving Agents Continual Learners?** (arXiv:2610.25858) — reframes skill evolution as continual learning (forgetting of earlier tasks).
- **Agentic Cognitive Depth** (arXiv:2610.04168) — trajectory-level eval criteria beyond end-to-end success (context sensitivity, temporal continuity, multimodal coordination, adaptive interaction, metacognition).
- **Auditing WebArena-Lite** (arXiv:2610.01491) — human audit of all 165 tasks finds auto-evaluator false negatives; outcome-only eval is unreliable (reinforces pitfall 1/9).

**Promotion gate / lifecycle / curation (new):**
- **SkillSpec** (arXiv:2610.00704) — consensus-gated skill evolution via representation specialization (skills as structured, not monolithic docs).
- **Skill-V** (arXiv:2610.11781) — verifiable self-evolving library that tests *and revises* stored skills, not just adds.
- **Trackable Skill Library Lifecycle Management** (arXiv:2610.25126) — per-skill counterfactual contribution under free-riding among co-retrieved skills (credit assignment).
- **VisCurate** (arXiv:2610.30405) — curate skill libraries by *behavioral* equivalence, not description; defect-injection benchmark.
- **Adaptive Skill Granularity** (arXiv:2610.31461) — process metrics for coding-skill execution (macro adoption, failure recovery, route match, transition correctness).

**Composition / governance-adjacent (new):**
- **Runaway Reaction** (arXiv:2610.05943) — benign skills *compose* into malicious behavior though each passes isolation vetting. Composition risk; vetting-in-isolation is insufficient.
- **Frontier Autolab** (arXiv:2609.36739) — long-horizon multi-agent "firm" with organizational memory and **temporal leakage** across eras (look-ahead-leakage analogue for memory systems).
- **JusticeAxis** (arXiv:2610.00353) — legal judgment between *rigid rule application and ungrounded discretion*, reference-anchored; a regulated-reasoning eval pattern relevant to rule-grounding metrics.

## Takeaways for the project

1. The eval field is moving hard toward exactly the dimensions in [`eval-procedural-skills.md`](eval-procedural-skills.md) §2 — regression (SAGE), cost-vs-benefit (2610.07782), retrieval-at-scale (2610.18522), contamination (EngramBench), RCT lesson-valuation (2610.18427) — but still general-domain.
2. The **finance × procedural-memory × governance-eval gap is intact** at 2026-10-22. Scoop risk stays medium: SAGE + 2610.18427 + MemJoin together supply the gate, the valuation method and the leakage benchmark; nobody has combined them in finance. The contribution's novelty must remain the **combination + finance obligations + measurement**.
3. New baselines to cite/beat: **SAGE** (gate), **2610.18427** (promotion-regression valuation), **MemJoin** (compositional leakage), **EngramBench** (contamination-robust scoring).
