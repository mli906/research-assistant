# arXiv:2606.15903 — Control-Plane Placement Shapes Forgetting: 13 agent-memory configurations (D. Yang, 2026-06-14)
Tags: mechanisms, core. Read: full text via arXiv HTML (WebFetch-assisted), 2026-09-24.

- **Problem:** Benchmarks test the recall plane. The control plane (supersede, release/TTL, purge) is largely untested.
- **Method:** ForgetEval: 1,000 templated cases across five families (supersession, decay, amnesia, purge, drift), plus a 385-case adversarial layer covering substring traps, prefix collisions, paraphrase supersession, negation, compound facts, identifier obfuscation, cross-lingual identifiers and more. Scored by deterministic substring match on the top 10 (Fleiss' κ = 0.958). Systems: Mem0 v2.0.2 (with and without infer), LangGraph InMemoryStore (with and without an LLM hook), Letta 0.16.7 (with and without hook), A-MEM, Graphiti, OpenMemory, HippoRAG, MemPalace, Lethe (with and without DeepSeek-V3 hook).
- **Results:** Deterministic systems pass 63–68% of the adversarial layer. An LLM at inscribe time (A-MEM, Mem0 infer) reaches 100% on canonicalisation but 0% on prefix-collision and compound-fact deletion. An LLM hook at mutation time reaches 91.7–94.2% overall, at about $0.17 per run and 2.3 s per mutation (vs 64–191 ms deterministic). MemPalace (no deletion) scores 0/385.
- **Stated limitations:** substring-scoring artefacts (about 30% of prefix-collision failures); English-centric; results depend on which LLM is used; some systems could not be run (Zep CE deprecated, Cognee API changes).
- **Critique:** This is the only cross-product *measurement* of forgetting correctness we found. It shows that deletion requests expressed in natural language ("forget my old account number") are brittle. Single-author work with a partly LLM-drafted suite. It is interface-level only, with no storage-layer check (compare Ghost Vectors).
