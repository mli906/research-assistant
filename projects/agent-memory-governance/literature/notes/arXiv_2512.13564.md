# arXiv:2512.13564 — Memory in the Age of AI Agents (Hu, Liu, Yue, Zhang et al., 2025-12-15)
Tags: mechanisms, core. Read: full text via arXiv HTML (WebFetch-assisted skim of taxonomy and Section 7), 2026-09-24.

- **Problem:** Agent-memory research is fragmented; long/short-term taxonomy no longer fits.
- **Method:** Survey organised by three lenses. *Forms*: token-level (flat/planar-graph/hierarchical), parametric (internal/external adapters), latent. *Functions*: factual (user/environment), experiential (case-, strategy-, skill-based), working memory. *Dynamics*: formation, evolution (consolidation, updating, forgetting by time/frequency/importance), retrieval.
- **Data/results:** No experiments; compiles benchmarks and open-source frameworks.
- **Stated open problems (Sec. 7):** retrieval vs generation of memory; automated memory management; RL for memory; multimodal memory; shared memory in multi-agent systems; memory for world models; trustworthy memory (framed as "from trustworthy RAG to trustworthy memory"); links to human cognition.
- **Critique:** The most useful current map of *mechanisms*, but governance is thin. Forgetting shows up as a utility/efficiency operator, not as an erasure obligation. Nothing on tenancy, audit, retention or regulation. It is a good backbone taxonomy that we can extend with a "governance operations" axis (authorise-write, scope-read, erase-with-derivatives, version/rollback, attest).
