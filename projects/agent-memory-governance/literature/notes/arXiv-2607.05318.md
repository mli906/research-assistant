# PiSAs: benchmarking contextual integrity in multi-user agentic systems (arXiv:2607.05318, 2026-07)
Read: full text (arXiv PDF, 39 pp; main text §3–5 and limitations read; appendices skimmed; reviewer, 2026-09-25). Tags: threats, gaps-check.

- **Setup.** 85 hand-built scenarios in one workplace domain (task types include JIRA allocation and severity classification), each with 4–10 users and about 23 attributes. Two annotations per attribute: task appropriateness, plus a **visibility matrix** of which users may legitimately access it. Two violation types: appropriateness and visibility (cross-user spillage). Surfaces measured: output, agent-to-agent messages and **memory**. Configurations: single, centralized and decentralized topologies; no/private/shared/hybrid memory. LLM judges with ablations; K=3 runs.
- **Key result.** Adding hybrid memory raises completeness by 5–10 points but **moves violations into memory**: total visibility violations rise from 36–47% to 63–90%. Prompt defenses cut only 28–29% of memory-channel violations.
- **Limits.** Retrieval mechanisms and pre/post interceptors are out of scope. It has a single domain and cooperative users. It is scenario-scoped rather than a long-lived multi-client store. There is no history-dependent access, and its legal norms are CI, not finance.
- **Relevance.** This is the closest generic precedent for GP2: it already measures cross-user spillage through shared memory with a who-may-see ground truth. GP2's novelty must rest on finance-specific structure (client relationships, barrier and wall-crossing dynamics, aggregation) and on enforcement mechanisms (pre-filter, partition), which PiSAs explicitly leaves out.
