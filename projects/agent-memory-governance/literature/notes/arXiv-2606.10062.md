# Deployment-Time Memorization in Foundation-Model Agents (arXiv:2606.10062v2, 2026-06-08/07-09)
Read: full text (arXiv HTML via curl + text extraction), 2026-09-25, by gap-analyst. Tags: pi-input, threats, gaps-check. License CC BY 4.0.

- **Problem.** Treats agent memory as a deployment-time memorisation mechanism: design knobs jointly shape personalisation, extraction risk and deletion fidelity.
- **Method.** Metrics: Personalization Recall (PR), Adversarial Extraction Rate (AER, canary-based), Forgetting Residue Score (FRS, residue in derived tiers). Knobs: summarisation aggressiveness, retrieval breadth k, deletion mode (five-mode ladder incl. noop, raw-only, raw_plus_resummarize, full_purge, tombstone). LongMemEval; Gemma 3 12B and GPT-4o-mini; replication on Llama and LoCoMo.
- **Results.** Key-fact summarisation cuts canary extraction 76% (Gemma) / 64% (GPT-4o-mini) with little PR loss; after compression, raising k no longer restores leakage. Raw-only deletion is statistically indistinguishable from noop in the summary tier (derived copies recoverable in ≈20% of instances). raw_plus_resummarize, full_purge and tombstone all drive worst-tier residue to zero.
- **Stated limitations (full text, Conclusion).** Headline frontier from two models; the forget benchmark "remains at [small n] pending a scaled rerun"; the high-entropy canary grammar "buys clean, judge-free attribution at the cost of ecological validity, since real deletion requests target semantically meaningful, paraphrasable facts that verbatim substring matching cannot detect". Next steps named by the authors: FRS for paraphrasable facts, "probing embedding- and cache-level residue beyond the text surface", more pipeline levers.
- **Bearing on gaps.** Closest published precedent for erasure completeness across derived tiers (GP4); text-surface only, so embedding/index/backup layers stay open. Its summarisation result is also a quantitative minimisation result (GP9). Tombstone redaction reaching zero residue while keeping a marker is a candidate retention-compatible erasure pattern (GP1), untested against record-keeping requirements.
