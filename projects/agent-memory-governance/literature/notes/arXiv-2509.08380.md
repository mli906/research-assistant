# Co-Investigator AI: agentic SAR narrative drafting for AML (arXiv:2509.08380)
Read: full text (arXiv HTML, 2026-09-24, via WebFetch extraction). Tags: finance-apps, core.

- **System.** A planning agent spawns typology-specific agents (crime-type detection, external intelligence, narrative generation, compliance validation with agent-as-judge). **Three memory layers:** regulatory memory (AML standards), historical narrative memory (**prior approved SARs**), typology memory (past patterns and indicators). An "AI-Privacy Guard" (RoBERTa-CRF) anonymises sensitive data before LLM calls. Investigators review and edit drafts.
- **Evaluation.** 6 investigators at an unnamed "leading global fintech". Narrative completeness 70% on average (up to 87% per typology); about 61% time savings. A direct-LLM baseline hallucinated at 20–30%. Data provenance (real vs synthetic) is not clear.
- **Critique.** This is the most explicit finance example of persistent memory holding **highly regulated content**. Prior SARs fall under confidentiality rules (e.g., 31 U.S.C. 5318(g)(2) prohibits disclosing SAR existence, to be confirmed by the regulation scout), and they are reused across cases. The paper does not discuss access control over narrative memory, retention (5-year SAR retention under BSA), or leakage of one subject's SAR into another's narrative. That is a concrete, underexplored governance gap. Evaluation is thin and industry-internal.
